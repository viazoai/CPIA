## 내러티브 through-line

```
[01] 무엇을 위한 도구인가     →  현장 운영 구조 전환을 위한 AI Agent (Why)
[02] 어떻게 일을 대신하는가   →  7-Agent가 작업일보를 자동 처리 (How — 손이 줄어든다)
[03] 무엇을 더 해주는가       →  사람이 못 보던 리스크를 당일 진단·만회 제안 (Value — 판단을 돕는다)
```

01은 "Why", 02는 "노동 절감(Middle Office 자동화)", 03은 "의사결정 지원(Front Office 강화)" 으로 역할이 나뉜다.
발표 전략 v04의 *"보고서 작성자 → 의사결정자로 전환"* 메시지와 1:1로 맞물린다.

## 촬영 환경 (공통)

| 항목 | 값 |
|------|-----|
| 권장 빌드 | **시연 빌드 5535** (`make build` 후 production standalone — 애니메이션/폰트 안정) |
| 대체 | 개발 5536 (`npm run dev`, HMR) — 빠른 수정 확인용. 녹화는 5535 권장 |
| 해상도 | **1920×1080 (FHD)** 고정. 레이아웃이 `xl`/`qhd` 분기를 타므로 녹화 직전 창 크기 확정 |
| 브라우저 | 시크릿 창 + 북마크바 숨김. 줌 100%. 마우스 커서 강조(하이라이트) ON |
| 시연 현장 | **M15X Ph-3 IBL** (청주) 단일 현장 |
| 시연 기준일 | 홈/작업 = **2025-09-25**, 리포트 = **9/24 기준** (fixture 고정 — UTC 기준 SSR/CSR 일치) |
| 페이스 | 클릭 후 **0.8~1초** 정지(애니메이션 완료 대기) 후 다음 동작. 차트는 그려지는 연출을 끝까지 보여줄 것 |

### 공통 캡처 규칙
- 각 페이지 진입 시 **상단 헤더(eyebrow + 제목 + 한 줄 설명)** 가 0.5초간 보이게 한 뒤 본문으로 시선 이동.
- 차트(생산성 추세선, 막대, 산점도, 예측 곡선)는 **진입 애니메이션이 다 끝난 뒤** 커서/줌으로 강조.
- 표/리스트는 천천히 스크롤(휙 넘기지 말 것). 강조할 행은 hover 로 잠깐 멈춤.

## 나레이션 톤

- 경영진 대상. **차분하고 단정한** 존댓말. 숫자는 또박또박.
- 기능 나열이 아니라 **"수작업이면 ~했을 일을, 지금은 ~"** 대비 구조로 말한다.
- 과장 금지. "약 92%", "약 5분" 처럼 추정치는 '약'을 붙인다.

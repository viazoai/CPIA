## 1. 요약 — 데이터가 말하는 것

이 문서는 CPIA 과제의 **추진 필요성을 외부 주입 논리가 아닌, 현장 담당자들이 직접 제출한 Activity 원본 데이터**에서 도출합니다.

Hi-tech 사업부 전체 321개 Activity(월 8,133h) 중, 공정 데이터 수집·보고·예측에 해당하는 **CPIA 대체 가능 업무가 126개(월 3,212h)로 전체의 39.5%를 차지**합니다.

| 구분 | 수치 | 의미 |
|------|------|------|
| CPIA 관련 Activity 수 | **126개** | Hi-tech 전체 Activity의 39.5% |
| CPIA 관련 월간 시간 | **3,212h/월** | FTE 22.9명 수준 |
| 6개 파일럿 현장 집중도 | **2,506h/월** | 대상 현장의 78% 이상이 CPIA 범위 |
| 동일 패턴 반복 현장 수 | **6개 현장** | 구조적 중복 문제 객관 확인 |

> **핵심 발견:** 현장 담당자들이 AI 자동화 수요로 스스로 제출한 업무 중 약 40%가 CPIA 과제가 해결하는 영역과 직접 일치합니다.

```

  공정률 산출·집계    ┃  ✓  ┃  ✓  ┃  ✓   ┃  ✓   ┃  ✓  ┃  ✓  ┃ → 6현장 모두 존재
  생산성 분석·리포트  ┃  ✓  ┃  ✓  ┃  ✓   ┃  ✓   ┃  ✓  ┃  ✓  ┃ → 6현장 모두 존재
```

## 4. 현장 담당자의 AI 수요: 방향성 일치 검증

Activity 원본 데이터를 분석하면, 현장 담당자들이 스스로 제출한 AI 적용 수요가 CPIA 설계 방향과 **놀랄 만큼 높은 일치도**를 보입니다.

| CPIA 설계 기능 | 담당자 제출 Activity (원문 발췌) | 일치 현장 수 |
|--------------|-------------------------------|------------|
| BP 작업일보 자동 수집·파싱 | "BP별 작업일보 취합 및 Summary 작업일보 작성" | 6/6 |
| 이상치 자동 감지 | "이상치(Outlier) 감지 및 검출", "데이터 이상치 검증 및 업체 협의" | 4/6 |
| 공정률·생산성 자동 산출 | "일일 실적 기반 잔여 물량 산출 및 생산성 추세 분석" | 6/6 |
| D-14 리스크 탐지 | "공기 미달 리스크 선행 탐지 자동화", "월단위 예상 Risk 확인" | 5/6 |
| 보고서 자동 생성 | "발주처 Weekly/Monthly Report 자동 작성" | 6/6 |
| 만회 시나리오 제시 | "만회 대책 시나리오 검토", "Hedge 방안 제공" | 3/6 |
| 자재 수급 예측 | "자재 과부족 예측 시스템", "자재 수급 리스크 및 부족 시점 예측" | 2/6 |

> **의미:** CPIA는 기획자가 상상한 솔루션이 아니라, **현장 담당자들이 직접 요청한 기능을 집약**한 것입니다.

## 6. 추진 시급성: "지금 해야 하는 이유"

### 이유 ①: 데이터 축적 시점이 임박

현재 진행 중인 6개 현장(Y-1, Indiana, M15X 등)은 **2~3년 내 주요 공정이 마무리**됩니다.
공기 예측 모델 훈련에 필요한 "진행 중 현장 데이터"는 지금만 확보 가능합니다.
종료 후에는 사후 데이터만 남아 선행 탐지 모델 품질이 크게 저하됩니다.

### 이유 ②: 중복 투자 방지

6개 현장에서 **각 팀이 독립적으로 동일한 AI 자동화 수요를 제출**했습니다.
조율 없이 진행 시, 각 현장이 유사한 솔루션을 개별 개발하는 낭비가 발생합니다.
CPIA는 이 중복 투자를 **한 번에 표준화**하는 플랫폼입니다.

### 이유 ③: 데이터 인프라는 먼저 구축해야 가치가 생긴다

현재 작업일보는 이메일·카카오톡·비정형 Excel 혼재 상태입니다.
지금 구조화 파이프라인을 구축하지 않으면, 쌓이는 데이터는 여전히 학습 불가능한 형태로 누적됩니다.
**구조화 DB 축적 없이는 Forecasting 고도화도 없습니다.**

### 이유 ④: Hi-tech 현장 검증 레퍼런스의 전략적 가치

SK에코플랜트 AI Solution 사업부가 추진 중인 외부 수익화 전략에서
**자사 Hi-tech 현장 검증 실적은 가장 강력한 영업 레퍼런스**입니다.
지금 구축하지 않으면 이 기회는 경쟁사에 선점될 수 있습니다.

## 7. 결론 — 추진 당위성 요약

```
  Activity 데이터가 증명하는 CPIA 과제의 타당성

  ① 규모: Hi-tech 사업부 전체 업무의 40%가 CPIA 범위 (3,212h/월)
     → 일부 현장의 특수한 문제가 아닌, 사업부 전체의 구조적 낭비

  ② 반복성: 동일 패턴 업무가 6개 현장에서 완전 중복
     → 한 번 해결하면 6배의 효과

  ③ 자발성: 현장 담당자들이 직접 AI 자동화를 요청한 업무와 CPIA 기능이 일치
     → 조직 저항 최소화, 현장 수용성 확보

  ④ 시급성: 진행 중인 현장의 데이터 축적 기회는 지금이 유일
     → 지금 시작하지 않으면 학습 데이터 기회 영구 소실

  ⑤ 확장성: Hi-tech 검증 후 전사·글로벌·외부 수익화 경로 확보
     → 단기 비용 절감 + 중장기 사업 기회
```

**CPIA는 "보고 자동화 도구"가 아닙니다.**
**Activity 데이터가 증명하듯, 현장 인력의 40%가 묶여있는 Middle Office 구조를 해체하고**
**그 역량을 공정 판단과 리스크 관리에 집중시키는 조직 전환 과제입니다.**

## 촬영 메모

- 랜딩은 **슬라이드 발표 모드**(`PresentationShell`). 첫 슬라이드(Hero)에서만 머물고 다음 슬라이드로 넘기지 말 것.
- Hero 우측 목업 카드는 **md 이상에서만** 보임 → FHD 가로 유지 필수(모바일 폭이면 사라짐).
- 버튼 클릭 → `/home` 전환 시 헤더 배경 이미지(`/site-hero-m15x.jpg`) 로딩이 끝난 프레임부터 사용. 첫 로드 시 살짝 깜빡이면 한 번 새로고침 후 재촬영.
- 30초 안에 카피를 다 읽으려 서두르지 말 것 — 나레이션이 카피를 *대신* 읽어주므로 화면은 천천히.

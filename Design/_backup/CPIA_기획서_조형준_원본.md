## BACKGROUND — 과제의 본질: 현장의 일을 재정립한다

이 과제는 단순히 현장의 보고 업무를 줄이는 자동화가 아닙니다.
현장 엔지니어가 수행하는 업무 중 **AI로 대체 가능한 Middle Office 레이어를 제거**하고,
그 인력을 **Front Office 본연의 역할(공정 판단·발주처 협상·리스크 실행)** 로 재배치함으로써
조직의 일하는 방식을 구조적으로 전환합니다.

### 건설 현장 3-Layer 구조

```
┌─────────────────────────────────────────────────────────────────┐
│  BP / 협력사 (작업일보 제출)                                       │
│            ↓                                                     │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │  MIDDLE OFFICE  ← CPIA 타겟                              │    │
│  │  데이터 중계·집계·보고서 작성·리스크 모니터링 (수작업)       │    │
│  │  → AI Agent로 대체                    [1,580h/월]        │    │
│  └─────────────────────────────────────────────────────────┘    │
│            ↓                                                     │
│  현장 PM / 경영진 (의사결정 집중)                                  │
└─────────────────────────────────────────────────────────────────┘
```

| Layer | 역할 | 건설 현장 예시 | CPIA 관계 |
|-------|------|----------------|-----------|
| **Front Office** | 수익 창출·의사결정 | 발주처 협의, 공정 문제 해결, 리스크 판단·실행 | 인력 집중 영역 (유지) |
| **Middle Office** | 데이터 중계·검증·보고 | 작업일보 취합, 보고서 작성, 공기 모니터링 | **CPIA 대체 대상** |
| **Back Office** | 기록·정산·시스템 | 기성 정산, 퇴직공제, ERP 관리 | 현행 유지 (범위 외) |

### Middle Office 제거가 아닌 "재설계"

```
❌ 잘못된 프레이밍: "Middle Office를 없앤다"
   → 조직 저항·불안감·인력 감축 논란

✅ 올바른 프레이밍: "Front가 AI Agent와 직접 일하는 구조로 전환한다"
   → Middle Office 인력 = Agent 오케스트레이터로 업스킬링
   → Front Office 역할이 더 명확해짐
   → 조직 구조적 AX 실현
```

### CPIA가 대체하는 Middle Office 4가지 기능

| 기능 | 내용 | 현재 월간시간 |
|------|------|--------------|

| ② P&L Reporting | 공정률·생산성 집계, Daily/Weekly/Monthly 보고서 작성 | 560h |

| ④ Deal Support | 주간회의 자료 가공·CPI/SPI 산출·만회 시나리오 초안 | 160h |
| **합계** | | **1,580h/월** |

## 01 — As-is vs To-be 프로세스

> **핵심 전환: 담당자 역할이 "보고서 작성자" → "의사결정자"로 이동합니다.**

### AS-IS — 현재 (수작업 7단계)

```
① BP 이메일·카카오톡 수동 열람    [1~2h/일]  ← 100개사+ 개별 확인
② 엑셀 복붙·집계 (수작업)         [2~3h/일]  ← 인원·물량·장비 수기 합산
③ 이상치 발견 시 업체 유선 확인   [1h/일]    ← 전화·문자 개별 협의
④ 공정표 항목 수작업 매핑                    ← Actual → Plan 수기 대조
⑤ PPT·엑셀 보고서 수기 작성       [2h/일]    ← S-Curve·공정률 표·시각화
⑥ 발주처 이메일 수동 발송                    ← D+2~3일 지연 발송
⑦ PM 경험칙으로 공정 이상 판단              ← 주간 회의 후 인지 → 이미 늦음
```

**결과:** 담당자 1~3명 전일 투입 | 보고 D+2~3일 지연 | 지연 발생 후 만회 불가 대응

---

### TO-BE — CPIA 적용 후 (5단계 자동)

```
① 이메일·카카오톡 자동 수집·파싱           ← 채널 통합 자동 수신 (0분)
② 이상치 자동 감지 → 담당자 알림           ← 전일 대비 급변 탐지 (확인 10분)
③ Semantic Mapping — 자동 분류             ← 비정형 텍스트 → 공정표 자동 매핑 (0분)
④ CPI/SPI 산출 + 보고서 자동 생성          ← S-Curve 자동 업데이트 (최종 검토 20분)
⑤ D-14 리스크 탐지 + 만회 시나리오 제시   ← 누적 추세 분석 → 3안 자동 제시
---
★ PM 판단 및 현장 조치 (인간 고유 역할)    ← AI 제안 검토 → 의사결정 → 실행
```

**결과:** 검토·승인 30분/일 | 보고 D+0 당일 | 공기 위험 D-14 선제 대응

## 02 — 통합 AI 파이프라인 구조

과제 A(데이터 수집·보고 자동화)와 과제 B(공기 예측)는 동일한 데이터 원천에서 출발하는 **연속 파이프라인**입니다.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                      5-STEP CONTINUOUS PIPELINE                              │
│                                                                              │
│  [STEP 1]        [STEP 2]        [STEP 3]        [STEP 4]       [STEP 5]    │
│  데이터 수집  →  정합성 검증  →  Mapping +    →  공기 리스크  →  만회 시나리오│
│                               보고서 생성       탐지           제시          │
│  이메일·카톡   이상치 감지     비정형 텍스트    누적 추세 분석  인원 증가/     │
│  자동 수신·    전일 대비       → 공정표 자동    잔여공기 예측  야간작업/      │
│  파싱·DB적재   탐지·알림       분류, 자동 발송  D-14 알림      공종 조정 3안  │
│                                                                              │
│  ◀────────────── 과제 A ──────────────▶  ◀──────── 과제 B ────────────▶    │
└──────────────────────────────────────────────────────────────────────────────┘
                         ↑
          Step 3 구조화 DB → Step 4 학습 데이터: 선순환 구조
```

### 과제 A + B를 통합하는 3가지 연결점

**연결점 ①** Output이 곧 다음 Input
> 과제 B가 필요한 "협력사별 일별 물량·인원 실적"이 과제 A의 산출물과 정확히 일치.
> 현재 B 담당자가 A 보고서를 다시 수기로 읽어서 작업 시작 → 중복 제거.

**연결점 ②** A가 B의 예측 품질을 결정
> A로 표준 구조화 DB가 쌓이면 B의 시계열 예측 정확도가 향상.
> 현재 비정형 엑셀 누적 데이터는 B의 학습 데이터로 활용 불가.

**연결점 ③** 보고 속도가 예측의 가치를 결정
> B가 D-14 위험을 탐지해도 A 보고서 완성에 3일 걸리면 실질적으로 D-11 경보.
> A·B 동시 자동화로 탐지-보고 Same-day 처리 가능.

### 공기 단축 4가지 경로

**경로 01 — 보고 사이클 단축 → 의사결정 가속**
```
현재: 보고 D+2~3일  →  AI: D+0 당일 처리
```
월 20~22일 기준 각 이슈의 의사결정이 2~3일 앞당겨짐.
이상 발생 → 현장 조치 사이 공백 제거. **공기 단축 3~5일 직접 기여.**

**경로 02 — D-14 선행 탐지 → 만회 가능 구간 확보**
```
현재: 지연 발생 후 사후 인지  →  AI: D-14 자동 알림
```
지연 2주 전 탐지 시 인력·장비 재배치 여유 확보.
업계 기준 **지연의 50~70%가 2주 전 탐지 시 예방 가능한 구간**에 해당.

**경로 03 — 자재 수급 선제 대응 → 현장 대기 제거**
```
현재: 자재 부족 후 긴급 발주 (대기 3~5일)  →  AI: D-21 예측 발주
```
BM·Drawing vs 입고 현황 자동 연계 분석.
자재 부족 대기 월 5~10건 × 평균 3일 = **월 15~30일분 현장 손실 제거.**

**경로 04 — 보고 업무 해방 인력 → 현장 집중 전환**
```
현재: PM급 인력의 80%+ 시간이 보고서 작성  →  AI: 공정 최적화·리스크 관리 집중
```
이 시간이 발주처 협상·리스크 관리로 전환 시 **공정 품질 5~10% 간접 개선.**

## 04 — 데이터 확보 현황

AI 학습 및 추론에 필요한 3종 데이터(Plan·Actual·Knowledge)가 현장 또는 관련 부서에서 **이미 확보** 되어 있습니다.
별도 인프라 구축 없이 현업 협조만으로 즉시 시작 가능합니다.

### 데이터 준비도

| 구분 | 데이터 종류 | 형태 | 준비도 |
|------|------------|------|-------|
| **Plan** | 실행내역서(Budget), 마스터 공정표(Schedule), WBS·CBS 코드, Staffing Norm | Excel, P6, CPMS | ✅ 즉시 활용 |
| **Actual** | BP 일일 작업일보, 비정형 텍스트 + 구조화 Excel 혼합, 현장 출입 타각기록 | 이메일·카카오톡·Excel | ✅ 즉시 활용 |
| **Knowledge** | 표준 품셈(공개), CPMS 표준단가, 과거 PJT 실적 DB, 공종별 생산성 기준 | 공개 데이터·사내 시스템 | ⚠️ 조건부 활용 |

> **보안 처리:** 실행내역·작업일보는 대외비 등급. 전사 AI 인프라(사내 승인 환경) 사용 전제.
> 고객 개인정보 미포함으로 규제 리스크 없음. AI혁신담당 협조 가능 상황 확인.

### AI 처리 3단계 흐름

```
STAGE 1 — Semantic Mapping
  비정형 작업일보 텍스트 → LLM 문맥 해석 → 공정표·실행내역 항목 자동 분류·할당
  (현재 담당자 수작업 중 가장 많은 시간 소모 구간)

       ↓

STAGE 2 — Reasoning (CPI/SPI)
  일단위 공정률·생산성 지표 자동 산출
  표준 품셈 대비 실적 비교, 효율 저하 구간 원인 추론
  (예산관리팀 90h/월 수작업 대체)

       ↓

STAGE 3 — Forecasting
  누적 실적 기반 잔여 공기 예측
  D-14 리스크 탐지, 인원·장비 재배치 만회 시나리오 3안 자동 제시
```

## 06 — 향후 확장성

Hi-tech 현장 검증 후 AI Solution 사업부, 글로벌 사업부, 나아가 타 건설사로의 복제가 가능한 구조입니다.
동일한 "BP 작업일보 → 공정 관리" 패턴은 건설 산업 전체가 공유하는 공통 Pain입니다.

### 확장 로드맵 (3 Horizon)

```
HORIZON 1 (0~6개월)       HORIZON 2 (6~18개월)      HORIZON 3 (18개월+)
Hi-tech 전 현장 검증  →   전사 사업부 확산       →   AI Solution 상품화

- Y-1 OBL 파일럿 완료      - AI Solution 사업부 적용   - CPIA SaaS 제품화
- 6개 현장 순차 확산        - 에너지·배터리 현장 확장   - 타 건설사 파일럿 영업
- 발주처 연동 표준화         - 글로벌(Indiana) 영문 지원  - 발주처 직접 서비스
- 경영진 대시보드 오픈       - 전사 통합 공정 대시보드    - AI Infra Solution 레퍼런스

월 1,586h 절감            월 4,200h+ 절감 추정       외부 수익화
```

### 확장 가능성 세부 검토

**① Hi-tech 사업부 내 전 현장**
- 현재 파일럿 6개 현장 → Hi-tech 전체 순차 확산
- 현장별 발주처(하이닉스·삼성) 보고 포맷 모듈화로 즉시 적용
- 현장간 생산성 벤치마크 → 우수 현장 노하우 전사 표준화

**② AI Solution 사업부 적용**
- 에너지사업관리팀 QG 품의 자동 작성(144h/월)과 공정 데이터 연동
- AI DC Infra솔루션팀 Pre-con 주간보고 자동화(35h/월)와 동일 구조
- 에너지 현장(연료전지·배터리) 특화 파서 추가만으로 확장

**③ 글로벌 사업부 적용**
- Indiana Fab HAC(미국)에서 파일럿 수행 → 글로벌 검증 가능
- 영문 작업일보 Semantic Mapping 모듈 추가 → 해외 BP 대응

**④ SK에코플랜트 AI Solution 상품화**
- 검증된 CPIA를 **AI Infra Solution Provider** 자체 솔루션으로 상품화
- Hi-tech 현장 검증 레퍼런스가 영업 신뢰도의 핵심 자산
- 타 건설사·발주처 대상 공정 관리 SaaS 형태 외부 수익화

## 핵심 메시지

> **CPIA는 "보고를 자동화"하는 것이 아닙니다.**
> **보고에 묶인 인력을 해방시켜 공기를 단축합니다.**

Hi-tech 현장 공기 지연 1일의 경제적 손실은 LD 리스크 + 간접비 추가로 수억~수십억원 규모입니다.
CPIA로 현장당 3~7일 공기 단축 시 투자 대비 수십 배의 ROI가 발생하며,
이 과제는 개인 생산성이 아닌 **Hi-tech 사업부 전체의 운영 방식을 바꾸는 조직 차원의 AX**입니다.

Middle Office 레이어를 AI Agent로 전환함으로써 현장 담당자는 데이터를 취합하는 사람에서
**데이터를 기반으로 판단하는 사람**으로 역할이 재정립됩니다.

# 클립 03 — 예측·최적화 모듈 · 2분 (120초)

> **목적:** 자동화로 모인 데이터 위에서 CPIA가 **사람이 못 보던 판단**을 어떻게 돕는지 보여준다.
> 핵심 메시지: *"오늘 생산성이 적정한지 당일 진단하고, 위험 공종에는 과거 사례 기반 만회 시나리오를 제시한다. 그리고 이 구조는 전사 6개 현장으로 그대로 확산된다."*
> **화면:** `/reports` (현장 일일 진단) → `/dashboard` (전사 모니터링)
> **분할:** Report 80s · Dashboard 40s

---

## 전체 흐름

```
[Report]  생산성 진단 → 4분면 리스크 → 위험 공종 만회 시나리오 ──80s──►  "당일 진단 + 근거 있는 조치"
   │
[Dashboard]  단일 현장의 진단 구조를 6개 현장으로 확장 ──40s──►  "한 번 만들면 전사 확산"
```

> 발표 전략 v04 *Core AI 02·03 (Forecaster · Optimizer)* + *Scalability* 구간의 실제 동작 증거.

---

## 1) Report — 현장 일일 진단 보고서 (0:00–1:20)

진입: `/reports` (좌측 일자 리스트에서 **9/24** 선택 상태). 헤더 *"현장 일일 진단 보고서"*.

### ① 생산성 진단 (0:00–0:25)

| 시간 | 화면 / 조작 | 화면에 보이는 것 | 나레이션 |
|------|-------------|------------------|----------|
| 0:00–0:10 | `/ 01 — 생산성 지표` 섹션, 생산성 추세선 차트가 좌→우로 그려짐 | 90일 **생산성 추세선** + 목표선(초록 100%) + 평균선(회색) + 오늘 시점 점 | "여기서부터는 '판단'의 영역입니다. 먼저 현장 생산성. 지난 90일 추세 위에, 오늘 값과 과거 평균·목표선을 겹쳐 봅니다." |
| 0:10–0:25 | 진단 2줄 텍스트 강조 → 하단 **업체별/WP별 막대** 토글 전환 | 자동 생성된 진단 문장 2줄 + 막대(목표 100% 미달은 빨강) | "AI가 '오늘은 어떤 날인지'를 문장으로 정리합니다. 어느 업체, 어느 공종이 평균을 끌어내리는지도 막대로 바로 짚어줍니다." |

### ② 4분면 리스크 진단 + 만회 방안 (0:25–1:05)

| 시간 | 화면 / 조작 | 화면에 보이는 것 | 나레이션 |
|------|-------------|------------------|----------|
| 0:25–0:38 | `/ 02 — 4분면 산점도` 섹션. KPI 카운트 + **Impact × Productivity 분포도** 산점도 | 4분면 산점도(정상·주의·위험), 상단 정상 n·주의 n·위험 n 카운트 | "오늘의 모든 공종을 'Impact(중요도)'와 'Productivity(생산성)' 두 축으로 흩뿌립니다. 우하단—중요한데 느린 공종이 위험군입니다. 별도 분석 없이 오늘 당장 어디를 봐야 하는지 보입니다." |
| 0:38–0:50 | 위험군 점 하나 클릭 → 우측 **진단 결과** 헤더(공종명·공기 단축 −N일·상태) 갱신 | 선택 WP 헤더 + 우측 OptimizerResult 패널 | "위험 공종 하나를 눌러보겠습니다. 우측에 그 공종의 진단과 만회 방안이 뜹니다." |

### ③ 공기 단축 예측 시나리오 (1:05–1:20)

| 시간 | 화면 / 조작 | 화면에 보이는 것 | 나레이션 |
|------|-------------|------------------|----------|
| 1:05–1:20 | `/ 03 — 공정률 추세` 섹션. **공기 단축 예측 시나리오** 곡선이 그려짐 | 기준일·계획 완공·현황(예측, 지연 D+N)·**AI 시나리오**(만회 곡선) | "마지막으로 예측입니다. 지금 추세대로면 준공이 얼마나 밀리는지(현황), 그리고 생산성이 과거 평균 수준으로만 회복돼도 며칠 만에 따라잡을 수 있는지(AI 시나리오)를 곡선으로 보여줍니다. **지연을 사후에 아는 게 아니라, 미리 대응합니다.**" |

**전환:** 상단 네비 **`Dashboard`(05)** 클릭 → `/dashboard`

> **촬영 메모:**
> - 좌측 일자 리스트는 sticky. 9/24 가 선택돼 있어야 진단 텍스트·산점도가 데모 데이터와 맞음.
> - 산점도 점 클릭 → 우측 패널이 바뀌는 인과를 또렷이. 위험(빨강) 점을 고를 것.
> - 예측 곡선의 4개 기준(기준일/계획 완공/현황(예측)/AI 시나리오)은 범례로 화면에 떠 있음 → 나레이션과 색을 맞춰 커서로 짚어줄 것.

진입: `/dashboard`. 헤더 *"전사 현장 모니터링"* · 탭 **Performance / Impact**.

| 시간 | 화면 / 조작 | 화면에 보이는 것 | 나레이션 |
|------|-------------|------------------|----------|
| 1:20–1:32 | **Performance** 탭 정지 — fleet KPI + 현장 카드 그리드 | 전사 생산성 추세 + **현장별 카드**(각 현장 생산성 스파크라인) | "지금까지 본 단일 현장 진단을, 전사 차원으로 올린 화면입니다. 6개 현장의 생산성을 한 화면에서 모니터링합니다." |

| 1:58–2:00 | 전체 대시보드로 줌아웃(마무리) | 전사 현황 풀샷 | "현장 하나의 자동화가, 전사의 운영 구조 전환으로 이어집니다." |

## 클립 03 마무리 자막 (2:00 직전 0.5초)

```
당일 진단(D+0)  ·  근거 있는 만회 시나리오  ·  전사 6개 현장 확산
보고서 작성자 → 의사결정자
```

## 전체 촬영 메모
- Report 는 세로로 긴 페이지 → 섹션 간 이동은 **부드러운 스크롤**. 차트 진입 애니메이션이 끝난 뒤 강조.
- Dashboard 탭 전환(Performance ↔ Impact)은 클릭으로. Impact 의 절감 수치가 발표 KPI(2,155h·15.4명)와 일치하는지 녹화 전 확인.
- 03은 "사람의 판단을 돕는다"가 메시지 → 02(노동 절감)와 톤을 구분. 숫자보다 **"미리 안다 / 근거가 있다 / 전사로 퍼진다"** 를 강조.

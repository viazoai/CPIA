# 생산성 시뮬레이션 결과

> **목적:** WBS 공정표·작업일보·품셈 데이터를 교차 검증하여 RC 3개 공종(철근·거푸집·콘크리트)의 실제 생산성을 산출하고, Forecaster·Optimizer PoC 구현을 위한 기준값과 계산 방법론을 확정
> **대상 현장:** M15X IBL PH-3 / 대상 업체: 남웅건설
> **데이터 기준일:** 2025-09-25
> **작성:** 2026.05.12

## 1. 분석 데이터 소스 및 방법론

| 소스 | 활용 내용 |
|------|---------|
| WBS 공정표 `Activity List(입력)` | Man-Hour(계획 투입 인·시간) + 주차별 누적 WV(Weighted Value) → 주간 소진 물량 |
| 통합 작업일보 시트2 `직종별 인원현황` | 직종별 누계 투입 인원 (주간, Cum.T) |
| 통합 작업일보 시트4 `물량` | 실제 완료 물량 (진도율 100%) |
| 품셈_건설_v2.json | 조 편성 인원 구성 + 조건별 시공량 |

**주간 소진 물량 계산 공식 (WBS 기반):**
```
해당 주 소진 물량 = (당주 누적WV - 전주 누적WV) / WV_Overall × 총물량
```

## 6. WBS Man-Hour 신뢰도 검증

| 공종 | WBS 계획 생산성 | 품셈 기준 | 비율 | 해석 |
|------|--------------|---------|------|------|
| **거푸집** | **6.14 m²/인·일** | **6.43 m²/인·일** | **95%** | ✅ WBS Man-Hour이 품셈과 거의 일치 |
| 철근 | 2.01 ton/인·일 | 0.275 ton/인·일 | 732% | ⚠️ 이 현장 공장 프리팹 비율이 높아 현장 조립 인원 실제 적음 |
| 콘크리트 | 1.34 m³/인·일 | 20.83 m³/인·일 | 6% | ⚠️ Man-Hour에 양생·보양·청소·관리 인원 전체 포함 |

**핵심 발견 — 거푸집으로 Man-Hour 신뢰도 확인:**

거푸집 Man-Hour은 품셈과 5% 이내로 일치. 이는 WBS 공정 계획 담당자가 실제 현장 작업 인원만을 기준으로 거푸집 Man-Hour을 산정했음을 의미. 반대로 콘크리트는 타설 인원 외 모든 관련 인원이 포함되어 스케일이 다르다.

**결론:** WBS Man-Hour은 거푸집 공종에 한해 직접 생산성 기준으로 활용 가능. 철근·콘크리트는 별도 보정이 필요하며, PoC에서는 거푸집을 생산성 검증의 앵커(anchor) 공종으로 사용하는 것이 권고.

## 7. 최적 투입 인원 역산

WBS 안정 구간 일일 생산량 + 품셈 기준으로 역산한 **필요 조 수 및 인원:**

### 콘크리트 (안정 구간: 2025-02~08, 30주 평균)

```
일일 평균 생산량:    779 m³/일
품셈 기준 조 생산성: 125 m³/조·일 (C-6-1-4, 철근구조물)
필요 조 수:          779 ÷ 125 = 6.2 조
필요 직접 타설팀:    6.2 × 6인 = 37명

실제 하루평균 타설공: 19,943 Cum.T ÷ 260일 = 77명
```

> 품셈 역산 37명 vs 실제 77명 = **2.1배 차이**
> 해석: 실제 타설팀 인원(37명) 외에 양생반, 보양반, 콘크리트 수급 대기 등 37명의 비생산 지원 인원이 추가로 투입됨. 타설 직접 인원 효율은 품셈 수준에 가깝다.

### 철근 (안정 구간: 2025-01~05, 18주 평균)

```
일일 평균 생산량:    115 ton/주 ÷ 5일 = 23 ton/일
품셈 기준 조 생산성: 2.2 ton/조·일 (C-6-2-3, Ⅰ-2 보통)
필요 조 수:          23 ÷ 2.2 = 10.5 조
필요 철근팀:         10.5 × 8인 = 84명

실제 하루평균 철근공: 51,525 Cum.T ÷ 260일 = 198명
```

> 품셈 역산 84명 vs 실제 198명 = **2.4배 차이**
> 해석: 2024-12-26 주에 WV 81%가 집중 계상됐으므로 실제 피크 구간은 그보다 이전이며, 그 기간에 더 많은 인원이 집중 투입됐을 것. 안정 구간 23 ton/일은 **잔여 마무리 공정** 수준이므로 84명이 오히려 과다. 실제 피크 구간에는 더 많은 조가 필요했을 것.

### 거푸집 (WBS 계획 기반)

```
WBS Man-Hour → 계획 생산성: 6.14 m²/인·일 (품셈 보통 6.43과 95% 일치)
총물량 17,140 m² ÷ 2,791 계획 인·일 = 약 267~267명·일 최대 집중
집중 2주(2024-12-26 ~ 2025-01-02): 17,140 ÷ 10일 = 1,714 m²/일
품셈 역산: 1,714 ÷ 45 × 7 = 267명 형틀팀

실제 하루평균 형틀공: 44,625 ÷ 260 = 172명
```

> 품셈 역산 267명 vs 실제 172명 → WBS 기준 집중도가 실제보다 높게 계산됨. 실제로는 2주가 아닌 더 긴 기간에 걸쳐 진행됐을 것.

## 8. Optimizer 시뮬레이션 — 가상 시나리오

> PoC 데모 시나리오 재현: 실행계획서 §2 데모 스크립트 기반 (실제 데이터 패턴으로 보정)

**시나리오 설정:**

```
현장 상황 (피크 구간 기준):
  잔여 철근 물량:     500 ton
  계획 완료까지:      20일
  현재 철근팀:        7명 (금일 투입 — 마무리 단계)
  거푸집 완료 여유 형틀공: 9명 (거푸집 100% 완료)
```

**① 재배치 전:**

| 항목 | 값 |
|------|---|
| 실측 생산성 | 0.316 ton/인·일 |
| 품셈 달성률 | 0.316 ÷ 0.425 = **74%** (품셈 Ⅰ-1 단순 기준) |
| 현재 일일 생산 | 7명 × 0.316 = 2.2 ton/일 |
| 완료 예상일수 | 500 ÷ 2.2 = **226일** |
| 지연 일수 | 226 - 20 = **206일** ⚠️ |

**② 형틀공 8명 → 철근 지원 재배치 후:**

| 항목 | 값 |
|------|---|
| 철근팀 총 인원 | 7 + 8 = **15명** |
| 신규 일일 생산 | 15명 × 0.316 = **4.7 ton/일** |
| 완료 예상일수 | 500 ÷ 4.7 = **105일** |
| 잔여 지연 | 105 - 20 = **85일** |
| 만회 효과 | **121일 단축** (추가 채용 0명) |

> ⚠️ **시나리오 한계:** 현재 기준일(2025-09-25)은 공사 마무리 단계라 7명은 잔여 마무리 인원. PoC 실제 시연에서는 **공정 중반의 현장 데이터**를 사용해야 더 현실적인 수치가 나옴. 아래 정규화 시나리오 참고.

**정규화 시나리오 (안정 구간 기준):**

```
피크 구간 기준 철근 데이터 재설정:
  잔여 철근 물량:     500 ton
  계획 완료까지:      30일 (피크 구간 실제 속도 기준)
  현재 일일 생산:     23 ton/일 (안정 구간 평균)
  → 완료 예상일수: 500 ÷ 23 = 22일 → 계획 내 완료에 가깝다

재배치 의미 있는 시나리오: 생산성이 품셈 대비 낮은 구간에서 적용
  예: 달성률 74% 구간, 잔여 500 ton, 10일 완료 목표
    현재 생산(74% × 品셈표준): 14명 × 0.316 = 4.4 ton/일 → 114일 필요
    → 형틀공 14명 투입 후: 28명 × 0.316 = 8.8 ton/일 → 57일 → 57일 단축
```

## 10. 핵심 발견 요약

### 데이터 신뢰도 판정

| 검증 항목 | 결과 | 판정 |
|---------|------|------|
| 거푸집 WBS Man-Hour ↔ 품셈 | 6.14 vs 6.43 m²/인·일 (95%) | ✅ 신뢰도 높음 |

### Forecaster 구현 방법론 확정

```
1. 실측 생산성 계산:
   실측_생산성 = 작업일보_금일물량 ÷ 작업일보_직종별_금일투입인원

2. 품셈 달성률 계산:
   달성률 = 실측_생산성 ÷ poom_sem_ref[공종][std_productivity_per_person]

3. 예상 완료일 계산:
   일일_예상생산 = 금일_투입인원 × 실측_생산성
   예상_완료일 = 오늘 + (잔여물량 ÷ 일일_예상생산)

4. 주의: 콘크리트는 타설공 인원에 ÷2 보정 계수 적용 권고
         (비생산 인원 약 50% 포함 추정 — 실제 현장 확인 후 조정)
```

### Optimizer 적용 원리 검증

- **거푸집 → 철근 재배치** 시나리오: 현실적으로 가능 (형틀목공이 철근 보조로 전환 가능)
- **재배치 효과 스케일:** 인원 7명 → 15명(+8) 시 생산량 2.2 → 4.7 ton/일 (2.1배)
- **품셈 조 편성의 의미:** 8인 조가 하나의 생산 단위이므로, 8명 단위로 조 추가/감소 시 선형 증감

## 11. PoC 구현 시 적용 체계

```
[작업일보 입력]
  공종: 건축  /  업체: 남웅건설
  철근 배근 금일 투입: 철근공 N명
  철근 배근 금일 물량: X ton

[Mapper]
  "철근 배근" + 공종 건축 → C-6-2-3 + poom_sem_ref["철근_현장조립"]

[Forecaster]
  실측 생산성 = X ton ÷ N명 = Y ton/인·일
  品셈 달성률 = Y ÷ 0.275 × 100%
  일일 예상 생산 = N × Y
  예상 완료일 = 오늘 + (잔여물량 ÷ 일일예상생산)
  지연/여유일 = 계획완료일 - 예상완료일

[H-i-L 2]
  리스크 공종(달성률 < 80%): 철근 [선택] / 콘크리트 [선택]

[Optimizer]
  선택 공종: 철근
  여유 공종: 거푸집 (진도율 > 110% → 형틀공 여유)
  재배치 계산:
    추가_투입시_일일생산 = (현재철근공 + 이동형틀공) × 실측_생산성
    단축_일수 = 잔여물량/현재생산 - 잔여물량/추가생산
  출력: "형틀공 N명 → 철근 이동 시 지연 M일 → K일로 단축 (추가 채용 0명)"
```
